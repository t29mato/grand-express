# アフリカ盤面の絵の鍵(絵の担当向け)

作成時刻: 2026-08-19。`cities.mjs` はまだ5都市のみ(承認待ちで停止中)。
以下は**今後60都市前後まで書き足す前提**で設計した、都市シンボル(`artGlyphKey`
= `city()` の `mark` 引数)と背景(`artSceneKey` = `city()` の `bg` 引数)の
一覧。既存の盤面(モロッコ32/22種・ガーナ・韓国17/12種)にならい、**似た性格の
町はキーを使い回す**前提で、それぞれ18種に絞った。

`cities.mjs` の5都市はすでにこの一覧のキーを使っている(`gauge`/`portrail`、
`junction`/`railjunction`、`electric`/`desertport`、`smelter`/`copperbelt`、
`peanut`/`atlanticport`)。残り13種ずつは、まだ書いていない都市のために
あらかじめ枠を用意したもの(採用都市は今後の執筆で確定する)。

## 厄災7件(`money-events`/`flavour` で使う予定)

大陸盤面の主題(鉄道インフラそのものの弱さ・政治・気候)に沿わせた。
特定の一国の民話を大陸全体の伝承のように語らないよう、実際に大陸各地で
繰り返し起きるインフラ上の出来事を題材にした(アジア盤面と同じ方針)。

| 名前(仮) | 何が起きるか | 効果の種類(予定) |
|---|---|---|
| サハラの砂嵐 | 線路が砂に埋もれ、掘り出す人足を雇う費用がかかる | `fine`(罰金) |
| 増水による洗掘 | 川沿いの土手が崩れ、線路脇の物件を失う | `loseProperties` |
| 突然の国境封鎖 | 政変や国境紛争で越境路線が急に閉じ、足止めを食う | `skipTurn` |
| 軌間の壁 | 台車の積み替えに手間取り、荷が傷んで値崩れする | `percentLoss` |
| 検問の袖の下 | 国境・州境の検問で袖の下を要求され、居合わせた全員に分け与える | `payOthers` |
| 保護区の迂回 | 野生動物保護区を横切る夜行便が迂回させられる | `teleport` |
| 架線の銅線盗難 | 電化区間の銅線が盗まれ、財産を奪われる(南部アフリカで実際に多発している問題) | `steal` |

## 迷った点・確認したいこと

- `capital` / `capitalcity` は「鉄道の物語がまだ薄い首都」用の予備枠。
  実際に何都市がこの枠を使うかは、都市を書き進めながら決める
  (できるだけ他のキーで書き切り、最後の調整弁として残した)。
- サヘル地域(マリ・ブルキナファソ・ニジェールなど)は現在ジハード系武装勢力の
  活動が国土の広い範囲に及んでいるため、**この地域から止まりマスの都市を
  選ぶかどうかまだ決めていない。**指示の「サヘルの一部は止まりマスにしない」
  に照らし、今回はダカールの文中でマリへの言及に留め、マリ・ブルキナファソ・
  ニジェールの都市そのものは選ばない方向で進める予定。異論があれば教えてほしい。
