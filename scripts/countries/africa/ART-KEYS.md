# アフリカ盤面の絵の鍵(絵の担当向け)

更新時刻: 2026-08-19。`cities.mjs` は60都市すべて書き終えた(team-lead承認済み)。
以下は**実際に60都市で使ったキーの最終版**。`artGlyphKey`(= `city()` の
`mark` 引数)18種・`artSceneKey`(= `city()` の `bg` 引数)17種。
どちらも `cities.mjs` から機械的に集計した実数で、未使用キーは載せていない。

## 厄災7件(`money-events`/`flavour` で使う。内容は変更していない)

大陸盤面の主題(鉄道インフラそのものの弱さ・政治・気候)に沿わせた。
特定の一国の民話を大陸全体の伝承のように語らないよう、実際に大陸各地で
繰り返し起きるインフラ上の出来事を題材にした(アジア盤面と同じ方針)。

| 名前(仮) | 何が起きるか | 効果の種類 |
|---|---|---|
| サハラの砂嵐 | 線路が砂に埋もれ、掘り出す人足を雇う費用がかかる | `fine`(罰金) |
| 増水による洗掘 | 川沿いの土手が崩れ、線路脇の物件を失う | `loseProperties` |
| 突然の国境封鎖 | 政変や国境紛争で越境路線が急に閉じ、足止めを食う | `skipTurn` |
| 軌間の壁 | 台車の積み替えに手間取り、荷が傷んで値崩れする | `percentLoss` |
| 検問の袖の下 | 国境・州境の検問で袖の下を要求され、居合わせた全員に分け与える | `payOthers` |
| 保護区の迂回 | 野生動物保護区を横切る夜行便が迂回させられる | `teleport` |
| 架線の銅線盗難 | 電化区間の銅線が盗まれ、財産を奪われる(南部アフリカで実際に多発している問題) | `steal` |

## 自分で確かめたこと(2026-08-19)

- 4言語(en/es/fr/ja)の欠落: `city()`/`t()` の検証(`|`が3本ちょうど、
  props2件ちょうど)を60都市・全フィールドで通過。例外0件。
- `node --check` / `npx eslint scripts/countries/africa/` ともに0件。
- mark18種・bg17種は、60都市から過不足なく参照されていることを機械集計で確認
  (上表の件数がそれ)。
- 物件価格: 現時点の暫定値で最安260〜最高1400(5.4倍)。**目安の12〜17倍に
  遠く届いていない。** これは今回、各都市を単独で書きながら控えめな額を
  置いたためで、**全都市が出そろった時点で価格帯を引き直す必要がある**
  (S目玉級を数都市に絞って2500〜2800まで引き上げる、C級は150前後まで
  下げる、など)。geography.mjs・flavour.mjs と並行してこの回でも直す。
- 座標の陸地判定: `world/geography.mjs` の `AFRICA`/`MADAGASCAR`/`ZANZIBAR`
  ポリゴンで機械確認したところ、**8都市が世界盤面用の粗い海岸線の外側に出た**
  (ダーバン・ナカラ・ワルビスベイ・ポワントノワール・コナクリ・フリータウン・
  モンロビア・スファックス・オラン)。都市の座標自体は実際の値のままで、
  `geography.mjs` を書く際にこれらの周辺の海岸線の解像度を上げて対応する
  (アジア盤面のジェッダ/マナーマと同種の既知の問題)。

## 迷った点・確認したいこと

- サヘル地域(マリ・ブルキナファソ・ニジェール)は、ジハード系武装勢力の
  活動が国土の広い範囲に及んでいるため**都市を置かなかった。**
  ダカール・コトヌー・アビジャンの文中でマリ/ニジェールへの言及に留めている。
  ンジャメナ(チャド)だけは、紛争そのものではなく「鉄道が一度も届いていない」
  という空白を主題にできる首都として`sah`枠に採用した。
- `border`(9件)と`capital`(6件)が想定よりだいぶ増えた。大陸盤面の主題
  (国境で切れる・閉じる話)が多いテーマなので自然な結果だと考えているが、
  **記号として9都市が同じ「遮断機とフェンス」で見分けがつくか**は絵に
  してみないと分からない。もし単調に見えるようなら、`border` の一部
  (特にヴィクトリアフォールズ・フランシスタウンなど「国境そのものが
  見どころ」の都市)を新しい鍵に分けることも検討してほしい。
