# アフリカ盤面の絵の鍵(絵の担当向け)

更新時刻: 2026-08-19(3回目)。`cities.mjs`・`geography.mjs`・`quiz.mjs`・
`flavour.mjs`・`money-events.mjs`・`music.mjs`・`index.mjs`・
`REGISTER.md` まで済んだ。60都市承認後、`toamasina`(マダガスカル海峡を
渡る航路の中継用)を61都市目として追加し、team-lead指摘を受けて
`bamako`・`ouagadougou`(サヘル、物差しは国ではなく町に当てる)を
62・63都市目として追加した。**キーの種類は増やしていない**
(既存の `riverport`/`rivercrossing`・`junction`/`railjunction` を再利用)。

以下は**63都市で使ったキーの最終版**。`artGlyphKey`(= `city()` の
`mark` 引数)18種・`artSceneKey`(= `city()` の `bg` 引数)17種。
どちらも `cities.mjs` から機械的に集計した実数で、未使用キーは載せていない。
`toamasina` 追加時に `port`/`harborcity` の件数がずれ、`antananarivo` の
bg誤り(`sahara`→`highlandpass`)を直し、絵の担当の助言で `walvisbay` の
bgも `sahara`→`desertport`(港町なのでこちらのほうが素直)に変えた。
下の表はすべて反映後の数字。

## 自分で確かめたこと(最終版・2026-08-19)

- 4言語(en/es/fr/ja)の欠落: `city()`/`t()` の検証(`|`が3本ちょうど、
  props2件ちょうど)を63都市・全フィールドで通過。例外0件。
- `node --check` / `npx eslint scripts/countries/africa/` ともに0件。
- mark18種・bg17種は、63都市から過不足なく参照されていることを機械集計で確認
  (上表の件数がそれ。種類は当初案から増やしていない)。
- 物件価格: 対数線形で引き直し、最安〜最高が**15倍**(他大陸盤面の実測値
  ——アジア14.4倍・ヨーロッパ15.3倍・北アメリカ12.7倍・南アメリカ14.7倍
  ——と並ぶ水準になった。目安の12〜17倍の範囲内)。運賃と収入の比率
  (約20.6%)は引き直し前後で変えていない。
- `carried-far`(向きの選べない移動)の `dhowpassage` が `roll-fixed-dice`の
  `coffeesack` と同額だったため260へ下げ、「操作できない移動は安く」の
  規則を満たすようにした。
- 座標の陸地判定: `world/geography.mjs` の粗い海岸線では8都市が海の外側に
  出ていたため、`geography.mjs` 側でダーバン・ナカラ・ワルビスベイ・
  ポワントノワール・コナクリ/フリータウン/モンロビアの半島部・スファックス・
  オラン周辺の海岸線を実測して解像度を上げ、63都市すべてが陸上にあることを
  機械確認済み。
- `check-sea-routes.mjs africa`(使い捨てJSONで実行、検査後に削除):
  海陸の取り違えは0件、唯一の例外は `toamasina-nacala`(136px・41%)で、
  マダガスカル海峡を渡る航路として代替の陸地終点を3通り試したうえで
  これが最善という結論(バリ盤面の `nusapenida-sanur` と同種のKEPT扱い)。
  team-lead側の共有 `KEPT` 一覧への追記待ち。
- `check-quiz.mjs africa`: 4言語欠落0件、日本語中のラテン文字混入は
  `M-Pesa`(登録済みの例外)のみ、解答の漏れは1件見つけて別の問題に
  差し替え済み(103問目、ジンバブエ内陸国の設問)。難易度9のンクルマの
  問いは、死去した場所(ギニアではなくブカレスト)の誤りを解説文のみ
  修正済み(問い・選択肢・正解は無傷)。

## 迷った点・確認したいこと

- サヘル地域の判断は、**国ごとではなく町ごとに切った**(team-lead指摘を
  受けて基準を改めた)。北部マリ(トンブクトゥ・ガオ)、ブルキナファソ
  北部・東部、ニジェールのティラベリ/リプタコ・グルマ三国国境地帯は
  実際に危険なので置かない。一方で**バマコ(マリの首都)・ワガドゥグ
  (ブルキナファソの首都)は、そこで人が普通に暮らし列車も走っている町**
  なので62・63都市目として置いた。とくにワガドゥグは、アビジャン〜
  ワガドゥグ(シタレール)が「貨物年間およそ100万トン(カカオ・綿・
  カシューナッツ・マンガン鉱)は今も動いているのに、旅客は2020年の
  コロナ国境封鎖以来ずっと止まったまま」という、大陸盤面の主題そのものの
  題材になったため、アビジャンの `fact` もこの事実に合わせて書き直した。
  ンジャメナ(チャド)は、紛争そのものではなく「鉄道が一度も届いていない」
  という空白を主題にできる首都として引き続き`sah`枠に採用している。
- `border`(10件)と`capital`(6件)が想定よりだいぶ増えた。大陸盤面の主題
  (国境で切れる・閉じる話)が多いテーマなので自然な結果だと考えているが、
  **記号として9都市が同じ「遮断機とフェンス」で見分けがつくか**は絵に
  してみないと分からない。もし単調に見えるようなら、`border` の一部
  (特にヴィクトリアフォールズ・フランシスタウンなど「国境そのものが
  見どころ」の都市)を新しい鍵に分けることも検討してほしい。
