# ノルウェー盤 `mark` / `bg` 一覧(board-artist 向け)

48都市。`mark`(盤面・都市カードのシンボル、直径19px)41種、`bg`(都市イラストの背景)
**29種**(記号+背景=計70枚、上限70枚に一致)。実測は `cities.mjs` のコメント参照。

**同じ絵になる都市は4組。**土地の性格が実際に同じ町どうしを意図的にまとめてある
(下記「背景の統合について」参照)。0組を目指して記号を増やす必要はない。

密度の目安(`docs/50-authoring/13-new-board.md` 追記2026-08-19):
背景1枚あたり40要素前後。都市シンボルが隠す帯(横151〜249・縦54〜152)を避け、
密度は下(y>170)と左右の端に置くこと。

### 同じ絵になる4組(意図的)

```
コングスヴィンゲル / フレドリクスタ   … どちらも星形要塞の町(mark も fortress で共通)
ドンボース / ドランメン               … どちらも鉄道の分岐駅(mark も junction で共通)
オッダ / モーシューエン               … どちらも水力で回る製錬所の町(mark も smelter で共通)
グリムスタ / シーエン                 … どちらもイプセンゆかりの町(mark も playwright で共通)
```

48都市の1割弱で、指示書の目安(4組以下)に収まる。土地の性格が実際に同じ
町を1組ずつ選んであり、無理に増やす必要はない。

## 重い題材について

`laborcamp`(モー・イ・ラーナ、捕虜労働)・`battle`(ナルヴィク、1940年海戦)・
`totaldestruction`(ハンメルフェスト、焦土作戦)・`sovietliberation`(シルケネス、
爆撃と解放)・`wwiimemorial`(ハルデン・モー・イ・ラーナ・ナルヴィク、共有背景)・
`scorchedearth`(ハンメルフェスト・ホニングスヴォーグ・アルタ、共有背景)は
史実の重い出来事を扱う。記念碑的・事実を示す描き方にし、装飾的・娯楽的に
見えないよう気をつけてほしい(茨城のダイダラボウ、韓国のDMZの描き方が参考になる)。
`wwiimemorial` と `scorchedearth` は「同じ理由で同じような姿になった町」を
まとめた背景であり、内容を薄めるための統合ではない。
