# ニュージーランド盤面の絵の鍵

`cities.mjs`(43都市。海に大きく出る路線を直すため、当初40件から
ファンガレイ・ワイトモ・アシュバートンを足した)で実際に使っている
`mark`(= `artGlyphKey`)と `bg`(= `artSceneKey`)の一覧。バリ方式
(mark と bg を別々の語彙にして使い回す)を採用しており、合計は
**mark 32種・bg 20種**。

## 数について(2026-08-19、取りまとめ側と確認済み)

守るべきは種類数そのものではなく次の規則:**`(mark, bg)` の組み合わせが
完全に同じ都市が2つあってはいけない**(同じ組み合わせだと、その2都市が
盤面上でも都市カードでも見分けの付かない同じ絵になってしまう)。

この規則にもとづき mark を当初の41種から32種に絞った。43都市 ×
`(mark, bg)` の組み合わせを機械的に確認し、**重複0件**を確認済み
(取りまとめ側でも再確認済み)。bg は20種のまま変更していない。

- **bg(背景)は20種。** 1種あたりの受け持ち都市数が多い(最大8都市)ぶん、
  **1枚1枚をフランス級(背景1枚に要素98・空/遠景/中景/近景/最前景の5層)に
  濃く描いてください。** 薄い背景(要素45未満)で描くと、同じ絵を
  4回見た人に使い回しだと気づかれます。
- **mark(記号)は32種。** 都市ごとの固有の見どころを拾いつつ、
  `(mark, bg)` の組み合わせが重複しないことを確認して絞った数。

## 厄災7種(`money-events` / `flavour` で使う。絵の担当が7枚のアニメを描く)

### タニファの扱いについて(取りまとめ側からの指示)

守り神は**タニファ**(taniwha)。マオリの伝承で**いまも真剣に扱われている
存在**で(道路計画がタニファを理由に実際に止まった例がある)、
扱いには次の2点を守ること。

1. **滑稽な化け物にしない。** 水辺の主として、敬意をもって描く
   (トッケビやダイダラボッチのような「間の抜けた愛嬌」の方向に寄せすぎない)。
2. **どの部族のどの水域のタニファ、と特定しない。** 総称として扱う
   (実在の特定のマラエ・河川・湖と結びつけない)。

`flavour.mjs` で書いた「害意ではなく縄張り意識が強すぎるだけ」という
性格づけ自体は取りまとめ側から**そのままで良い**と確認済み。

| id | 名前 | 何が起きるか |
|---|---|---|
| `ruapehu-ash` | ルアペフの降灰 | 火山灰が線路と道路に積もり、列車が止まる。1995〜96年の実際の噴火を踏まえた、灰まみれの機関車の絵。 |
| `norwester` | ノーウェスターが吹く | カンタベリー名物の高温乾燥のフェーン風。看板が揺れ、フェリーが欠航する強風の絵。 |
| `flood-washout` | 川が鉄橋を洗い流す | 増水した川が橋脚を洗い、線路が宙に浮く。迂回を強いられる。 |
| `sandflies` | サンドフライの大群 | 西海岸・フィヨルドランド名物の吸血バエに囲まれ、たまらず腕を振り回す絵。 |
| `ferry-cancelled` | クック海峡が荒れる | 高波でフェリーが欠航し、埠頭で足止めを食う。 |
| `taniwha-lost` | タニファに化かされる | 道が堂々巡りになり、同じ場所を何度も通ってしまう。守り神本人の悪戯(上記の扱い方を参照)。 |

(厄災7件の4言語文章)を参照してください。
