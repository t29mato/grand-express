## 厄災7件(`spain-*` の doom アニメ)

韓国のトッケビ(道具の化身、いたずら好き)にならい、こちらも**残酷な悪霊では
なく、程度が過ぎるだけの厄介者**として描く想定です(厄災の神そのものの
デザインは flavour.mjs 側で詰めます。7枚のアニメは以下の出来事そのものを
描くもの)。

| id | 名前 | 何が起きるか |
|---|---|---|
| `calima` | カリマ(サハラの砂塵) | サハラ砂漠からの南風で空が橙色に煙り、車や洗濯物に赤茶けた砂の膜が張る。目と喉をやられて足止め。 |
| `ola-calor` | 熱波でレールが曲がる | 記録的な暑さでレールが歪む恐れがあるとして速度制限がかかり(実際にスペイン国鉄が行っている措置)、列車が徐行して遅れる。 |
| `dana` | ゴタ・フリア(秋の集中豪雨) | 地中海側特有の秋の急な豪雨(通称DANA)で川が増水し、線路が冠水して運休する。 |
| `huelga` | 鉄道スト | 労働組合の一斉ストライキで最低限の便しか動かず、乗れる列車がほとんど無い。 |
| `siesta` | シエスタで何もかも閉まる | 昼の数時間、窓口も商店もいっせいに閉まり、切符も買えず足止めを食う。 |
| `procesion` | 行列で道が封鎖される | セマナ・サンタの行列や地元の祭りで大通りが歩行者に占拠され、駅にたどり着けない。 |
| `carterista` | 市場ですりに遭う | 混み合う市場ですりに遭う(財布が軽くなっているのに次の店まで気づかない)。 |
