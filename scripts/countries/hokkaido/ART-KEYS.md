# 北海道盤面 絵の鍵(board-artist 向け)

`art.mjs`(盤面マーカー `marks` + 都市イラスト背景 `bg`)を描くための一覧。
`cities.mjs` は**この一覧の時点で凍結**している。担当が絵を描き終えるまで、
文章担当は都市を1件も足さない。

合計 **32 mark + 23 bg = 55枚**(上限70枚以内)。
同じ絵(mark+bg の組み合わせが同一)になる都市は **1組のみ**(夕張×歌志内。
どちらも同じ理由で同じ姿になった炭鉱町なので、意図して揃えてある。40都市の
1割以内)。

人物・顔は描かない(白老は `chise` = 建築で表す)。文字要素は使わない
(`dooms.test.ts` と同じ理由。地名などを描き込みたい場合は線で表現する)。

## 注意点(他盤面で実際に踏んだ穴)

- **背景の見えない帯**: 都市シンボルが4.1倍で重なるため、横151〜249・縦54〜152は
  見えない。密度は下(y>170)と左右の端に置くこと(`docs/50-authoring/13-new-board.md`)。
- **手前に描いたものが `ground()` に塗りつぶされる**: `sky()` → 丘 → `ground()` →
  手前のもの、の順で呼ぶこと。
- **`sky()` の第3引数を渡し忘れない**こと(空と地面の継ぎ目が透ける)。
- 描き終えたら**マゼンタ台紙の上でPNG化して目視**すること。
