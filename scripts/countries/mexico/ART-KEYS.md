# メキシコ盤面の絵の鍵(絵の担当向け)

`cities.mjs` の `mark` が `artGlyphKey`、`bg` が `artSceneKey` に対応します
(`src/infrastructure/content/country-content-mapper.ts` 参照)。実際のキー名は
`cities.mjs` に書いた文字列そのままです(接頭辞は付けていません)。

- `artSceneKey`(= `bg`)… 都市カードの背景シーン(400×210)。**18種**
- `artGlyphKey`(= `mark`)… 盤面上で直径19pxほどの小さなシンボル。**38種**
  (team-leadの目安「30前後」よりやや多いですが、45都市を7地方に分けたとき
  **同じ地方の中では極力キーが重ならない**ようにしたら38になりました。
  地方をまたいだ重なりは意図的です。**2026-08-19、45都市ぶんのcities.mjsが
  確定した時点で機械的に数え直し、以前このファイルに書いていた「33種」が
  誤りだったと判明しました(`cactus` の1件が表から漏れており、かつ
  以前の集計そのものにも数え間違いがありました)。以下の表は
  `cities.mjs` の実際の値と一致させてあります**)

似た景色・記号はまとめてあります。1つのキーを複数の都市が共有します。

## 厄災7件(`money-events` / `flavour` で使う。絵の担当がアニメ7枚を描く)

盤面の「厄災の神」役は、ナワトル系の民話に伝わる**チャネケ**(森や水辺を
守るいたずら好きの小さな精霊)を想定しています。トッケビ(韓国)や
だいだらぼう(茨城)と同じく、**残酷な悪霊ではなく、度の過ぎたいたずら者**
として描いてください。

| id | 名前 | 何が起きるか |
|---|---|---|
| `huracan` | ハリケーンが上陸する | 太平洋岸かメキシコ湾岸に季節性のハリケーンが上陸し、屋根や看板を吹き飛ばし、沿岸の足を止める。事前に進路が追われているのは韓国の台風と同じ |
| `temblor` | 地震が来る | メキシコは環太平洋火山帯に位置し、地震が日常的なリスクとしてある。棚のものが落ち、しばらく揺れの余韻に身構える、という程度の描写(特定の災害年を名指ししない) |
| `ceniza` | 火山灰が降る | ポポカテペトル山などの活火山が噴煙を上げ、灰が空港の便を止め、洗濯物や畑の作物を薄く覆う |
| `contingencia` | 大気汚染で車が締め出される | 首都圏の「今日は走れない(Hoy No Circula)」のような大気汚染時の自動車通行規制。ナンバー末尾で締め出される日が決まり、電車やバスが混み合う |
| `chaneque` | チャネケに化かされる | 森や水辺の精霊チャネケに気に入られ、同じ道を何度も歩かされて足止めを食う。トッケビに化かされる話と同型(意地悪ではなく、いたずら) |
| `ratero` | 市場ですりに遭う | 混み合うティアンギス(青空市)で肩がぶつかった拍子に財布をすられる。次の店に着いてはじめて気づく |
| `padrino` | キンセアニェーラの代母/代父に指名される | 十五歳の誕生祝い(キンセアニェーラ)や結婚式で、特定の品目(ケーキ・音楽・ドレスなど)を丸ごと持つ「パドリーノ/マドリーナ」に指名され、その場で断れず費用を持つ羽目になる |

**麻薬組織関連の題材は入れていません。**指示どおり「いま人が普通に暮らす町」を
物差しにし、厄災も天災と生活の中の小さな災難に絞りました。
