# 南アフリカ盤 — `mark` / `bg` 一覧(絵の専任向け)

`art.mjs` はまだありません。ここに列挙した37種の `mark`(盤面・都市カードの
シンボル、直径19px前後)と33種の `bg`(都市イラストの背景)を、
`SOUTHAFRICA_MARKS` / `SOUTHAFRICA_BG` として `art.mjs` に実装してください。

正は `cities.mjs` です(このファイルは都市が変わるたびに手で更新するので、
ずれていたら `cities.mjs` を信じてください)。

**絵の枚数は記号+背景で70枚以内という上限があります**(2026-08-19、
取りまとめ側の指示)。2026-08-20実測で **記号37+背景33=計70枚**、
ちょうど上限に収まっています。これ以上、鍵を増やさないでください。

同じ絵になる都市(mark+bgの組み合わせが重複する都市)は**1組**
(ステレンボッシュ/フランシュフック。上限4組の範囲内)。**この1組は
意図的です。**どちらもケープワインランズの谷にある、オークの並木と
ワイン農園の町で、記号「vineyard」も背景も共有させています(無理に
散らして嘘の描き分けをするより、似ている土地は似せるほうが正確)。

## 意図的に背景を共有させた5組(理由つき)

土地の性格が本当に同じ町は、無理に描き分けず背景を共有させています。
**違いは記号のほうで語ってください。**

| 背景キー | 受け持つ町 | 共有させた理由 |
|---|---|---|

| `homelandcapital` | ムタタ・ビショ | どちらもアパルトヘイト時代のホームランド(バントゥースタン)の首都。行政庁舎が農地の中に唐突に建つ光景が共通する。記号(rondavel/capital)で違いを出す |
| `capewinelands` | ステレンボッシュ・フランシュフック | ケープワインランズの谷。オーク並木とケープダッチ様式の農園が共通する。記号も両方vineyardで、絵としては同一になる(上記の1組) |
| `krugergate` | ムボンベラ・スクザ | クルーガー国立公園の玄関口。茅葺き・木材・低木のブッシュフェルトの景観が共通する。記号(rondavel/safari)で違いを出す |

## 密度の目安

`docs/50-authoring/13-new-board.md` 追記(2026-08-19)を参照。**背景1枚あたり
40要素**を目安に(韓国27=薄い、イタリア48が濃いほう)。背景の中央25%
(横151〜249・縦54〜152、盤面によって座標は変わるので実測すること)は
都市シンボルに隠れるので、密度は下(y>170相当)と左右の端に置くこと。

**背景を複数の町で共有する場合(上表の6組)は、それぞれの町のカード文章
(`fact`)を読んでから描くこと。**同じ背景でも、カードに書かれた具体的な
事実(何年に何が起きたか)は町ごとに違うので、細部の小道具はその町の話に
合わせてよい(例:`goldbelt` の中でも、カールトンビルは深い立坑、
ウェルコムは同心円の街路、ゲルミストンは精錬所の金庫室、という具合)。
