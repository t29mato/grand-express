# ベトナム盤面の絵の鍵(絵の担当向け)

`cities.mjs` の `mark` が `artGlyphKey`、`bg` が `artSceneKey` に対応します
(`src/infrastructure/content/country-content-mapper.ts` 参照)。実際のキー名は
`cities.mjs` に書いた文字列そのままです(接頭辞は付けていません)。

- `artGlyphKey`(= `mark`)… 盤面上で直径19pxほどの小さなシンボル。**43種**(43都市、1都市1種)
- `artSceneKey`(= `bg`)… 都市カードの背景シーン(400×210)。**25種**(似た景観の都市でまとめてある)

同じ mark+bg の組み合わせを持つ都市は0組(43都市/43組み合わせ、機械確認済み、
2026-08-20時点)。**背景は複数の都市で共有されるので、記号(mark)のほうで
都市を見分けられるようにしてください。**

## 厄災の神とアニメーション7枚(`money-events` / `flavour` で使う)

盤面の「厄災の神」役は**マー・チョーイ**(鬼火。墓地から立つ蒼白い彷徨う炎という
ベトナムの民話上の存在)です。韓国のトッケビ・茨城のだいだらぼうと同じく、
**残酷な悪霊ではなく、度の過ぎたいたずら者**として描いてください。

| id | 名前 | 何が起きるか |
|---|---|---|
| `bao` | 台風が中部沿岸を通る | 南シナ海から来た台風が沿岸に上陸し、屋根や看板を吹き飛ばす。中部の省(ドンホイ〜ダナン周辺)が主戦場 |
| `lut` | メコンデルタの増水期が押し寄せる | メコンの水が「浮き水」として田や道に広がる、想定内だが度を越すと道路や市場が水浸しになる |
| `nong` | 熱波が中部沿岸を焼く | 山から吹き下ろす乾いた「火の風」で気温が40度を超え、線路が歪んで列車がのろのろになる |
| `ketxe` | 大渋滞が街を飲み込む | 一台のトラックの立ち往生で、両方向何キロもバイクが連なる都市の日常的な渋滞 |
| `chaunhau` | 乾杯ゲームに負けて全員分を払う | サイコロの乾杯ゲームに三連敗し、店の決まりで全員のグラス分を持たされる |
| `matroidat` | マー・チョーイに化かされる | 夜道で同じ田んぼの畦道を何度も歩かされ、堂々巡りする(トッケビに化かされる話と同型) |
| `chomoctui` | 市場ですりに遭う | 混み合う露店で肩がぶつかった隙にポケットの財布を抜かれる |

**マー・チョーイの絵の要は「蒼白く漂う炎」であって、人型の妖怪ではありません。**
淡い緑がかった白〜青の光の玉や揺らめく炎として描いてください(`wakeFact` に
「実は墓から出るリン化水素・メタンガスの発光」という科学的背景を書いてあります)。
