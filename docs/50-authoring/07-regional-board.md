# 県単位の盤面は作れるか(結論: 作れる)

「つくば・大洗のような粒度を入れるなら、日本全体ではなく茨城県の盤面を作るべき」
という案への回答。

## 結論

**いまの仕組みのまま作れる。** 新しい概念は要らない。

根拠は、この仕組みが**縮尺に依存していない**こと。実際に3つの縮尺で動いている。

| 盤面 | 経度の幅 | 都市 |
|---|---|---|
| フランス | 14.8度 | 50 |
| 日本 | 23.7度 | 74 |
| 世界一周 | 360度 | 60 |

投影は `LON0/LON1/LAT0/LAT1` を盤面 `BW×BH` に引き伸ばすだけなので、
県の範囲(茨城なら東経139.6〜140.9度、北緯35.7〜36.9度)を入れれば同じように動く。

## 茨城県の盤面を作る場合

`scripts/countries/ibaraki/` に、フランス・世界一周と同じ7ファイルを置く。

- **投影**: `LON0: 139.55, LON1: 140.9, LAT0: 36.95, LAT1: 35.7`
  経度1度と緯度1度の見た目を揃えるなら、緯度36度の cos(≒0.81)を掛けて
  `BW : BH = 1.35 × 0.81 : 1.25` → おおよそ `BW: 1500, BH: 1700`
- **地方区分**: 県北 / 県央 / 鹿行 / 県南 / 県西 の5つ(県が実際に使う区分)
- **季節**: 12ヶ月のまま。県単位なら地方ごとの収入差は小さくなるので、
  「霞ヶ浦の水位」「筑波山の梅」「大洗の海開き」のように**行事で差をつける**とよい
- **厄災の神・災難・アイテム**: 各7〜9件。日本のものを流用せず、茨城のものを書く
- **都市**: 30〜40件(水戸・つくば・大洗・日立・笠間・鹿嶋・古河・土浦・
  袋田・那珂湊・牛久・結城・下館・北茨城 など)


## 注意する点

- **国選択の画面が縦に伸びる。** 今は4つ(ボリビア・日本・インド・世界一周)。
  県を足していくと増え続けるので、5つを超えるあたりで「国」と「地域」を
  分けて見せる工夫が要る
- 県の盤面では**目的地までの距離が短くなる**ので、賞金の式
  (`700 + 70×月`)が相対的に大きすぎないか確認すること
