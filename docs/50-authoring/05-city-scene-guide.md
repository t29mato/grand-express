# 都市イラストに動きを足す

都市カードの背景(43種)に、その土地の**空気の動き**を重ねる。

## 考え方

背景そのものは legacy から引き継いだ静止SVGで、これは書き換えない。
その上に**透明な重ねレイヤー**を1枚置いて、雲・波・湯気・雪などを動かす。

こうする理由は2つ。

- 43枚を描き直すより安全で、既存の絵が壊れない
- 「その土地らしい動き」だけを足せばよく、1枚あたりが小さく済む

## 置き場所と名前

`src/presentation/components/city/scenes/<国>-<背景キー>.tsx`
export する関数名はファイル名のPascalCase(例: `japan-port.tsx` → `JapanPort`)。

背景キーは `src/infrastructure/content/<国>.content.json` の `bg` のキー。

## 仕様

出来事アニメーションとほぼ同じ([02-animation-guide.md](./02-animation-guide.md))。違いは2点。

1. **背景は描かない。** 空・地面・建物は下の静止画がすでに描いている。
   重ねるのは動くものだけ(雲・波・湯気・雪・鳥・木の葉・熱のゆらぎなど)。
   `<rect width="400" height="210">` のような塗りつぶしは**置かない**。
2. **控えめにする。** 都市カードは読み物なので、動きが主張しすぎると
   文字が読みにくい。ゆっくり・小さく・半透明を基本にする。

それ以外(viewBox 0 0 400 210 固定・自己完結・無限ループ・
`prefers-reduced-motion` で停止・`<text>` 禁止)は同じ。

## その土地らしい動きの例

| 背景 | 足すもの |
|---|---|
| 港・海辺 | 波の白い筋、かもめ、船の揺れ |
| 雪の街 | ゆっくり降る雪、窓の灯りのゆらぎ |
| 火山 | 噴煙、熱のゆらぎ |
| 温泉 | 立ちのぼる湯気 |
| 田園 | 稲の穂の波、とんぼ |
| 大都市 | 窓の灯りの明滅、流れる車のライト |
| 砂漠 | 砂の帯、陽炎 |
| 熱帯 | 雨粒、椰子の葉のそよぎ |

## 確認

```
npm run preview -- src/presentation/components/city/scenes/japan-port.tsx /tmp/a.png
```

**重ねレイヤーだけなので、単体で見ると背景が透けて見える。** それが正しい。
