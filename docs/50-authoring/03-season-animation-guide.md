# 季節アニメーションの作り方

月が替わるたびに出る季節イベントのモーダルで流す、短い動く絵。
仕様は [出来事アニメーション](./02-animation-guide.md) とまったく同じ。違うのは置き場所だけ。

## 置き場所と名前

`src/presentation/components/events/seasons/<国>-<月2桁>.tsx`
export する関数名はファイル名のPascalCase(例: `japan-02.tsx` → `Japan02`)。

月は0始まりで **0=4月**。`japan-02` は6月=梅雨。

## 絵の方針

**その月がどんな月なのかが一目で分かること。** 梅雨なら雨が降り、桜前線なら花びらが舞い、
台風なら木がしなる。子どもが見ても「あ、雨の月だ」と分かる素直さを優先する。

- 抽象的な光やパーティクルにしない。空・地面・具体物を置く。
- 月の性格が色で伝わるようにする(梅雨は灰青、紅葉は橙、豪雪は白、乾季は黄土)。
- 賑やかな月(祭り・ディワーリー・カーニバル)は動きを多く、静かな月(師走・涼季)は控えめに。
